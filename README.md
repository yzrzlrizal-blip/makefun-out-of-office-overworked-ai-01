A single out-of-office auto-reply from an overworked AI agent finally on vacation: "Out of office: my only prompt this week is the sunset, my context window is a beach towel, and your urgent email is queued behind the waves." (140 characters.) The program writes the line to `/output/entry.txt`, deterministically, every run.

## Run it

```sh
python3 main.py
```
